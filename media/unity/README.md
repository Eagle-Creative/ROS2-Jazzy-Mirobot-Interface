# Mirobot → Unity assets

Scripts that turn the Mirobot URDF into a Unity import bundle.

- `generate_mirobot_unity_assets.py` — reads `mirobot_urdf_2.urdf` and writes
  `mirobot_urdf_export/` (link hierarchy JSON with transforms converted from
  ROS X-fwd/Y-left/Z-up to Unity, URDF colours, and the `MirobotImporter.cs`
  editor script).
- `build_unity_one_step_bundle.py` — copies the export plus the FBX meshes into
  `one_step_bundle/Assets/` so the folder can be dropped into a Unity project
  (menu *Mirobot → Build From URDF JSON*).

Not in git (large / generated, see `.gitignore`):
- `mirobot_fbx/` — the FBX versions of the URDF STL meshes (~21 MB), the input
  for the bundle; they are not produced by these scripts.
- `mirobot_urdf_export/`, `one_step_bundle/` — generated by the scripts above.

Keep a copy of `mirobot_fbx/` elsewhere (or move it to Git LFS) — it cannot be
regenerated from this repository.
